# 🏃‍♂️ Piano Allenamento 6 Mesi - Versione Bilanciata

Piano di allenamento personalizzato di 6 mesi che combina **tonificazione muscolare** e **performance running** per preparare una mezza maratona mantenendo e costruendo massa muscolare.

## 🎯 Obiettivi

- **Mezza Maratona:** 1:48-1:50 (miglioramento di 9-11 minuti)
- **Composizione Corporea:** +1-1.5 kg massa muscolare, -1-2 kg grasso
- **Circonferenza Vita:** -3-4 cm
- **Risultato:** Corpo tonico e definito + Ottime performance running

## 🔑 Caratteristiche Chiave

### Approccio Bilanciato
Questo piano è ottimizzato per **massimizzare la tonificazione** senza sacrificare troppo le performance running:

| Aspetto | Valore |
|---------|--------|
| **Volume corsa settimanale** | 35-44 km |
| **Lungo massimo** | 22 km (MAX 2 ore) |
| **Sessioni forza** | 2x settimana (60' ciascuna) |
| **Proteine giornaliere** | 165-180g (2.2-2.4 g/kg) |
| **Deficit calorico** | -100-150 kcal (minimo) |
| **Surplus giorni forza** | +100-200 kcal |

### Periodizzazione

**Mesociclo 1 (Sett 1-8):** Base aerobica + Costruzione muscolare  
**Mesociclo 2 (Sett 9-16):** Soglia anaerobica + Ipertrofia massima  
**Mesociclo 3 (Sett 17-24):** Picco performance + Mantenimento muscolare

## 💪 Struttura Settimanale

| Giorno | Allenamento | Durata | Focus |
|--------|-------------|--------|-------|
| **LUN** | Full Body A | 60' | Spinta + Core (Ipertrofia) |
| **MAR** | Ripetute | 50-65' | Velocità Z4-Z5 |
| **MER** | Riposo | - | Recupero completo |
| **GIO** | Z2/Tempo | 60-75' | Aerobico Z2-Z3 |
| **VEN** | Full Body B | 60' | Trazione + Gambe (Ipertrofia) |
| **SAB** | Lungo | 90-135' | Resistenza Z1-Z2 (MAX 2h) |
| **DOM** | Recupero Attivo | 30-45' | Mobilità/Camminata |

## 🍽️ Nutrizione

- **Proteine:** 165-180g/giorno (priorità assoluta)
- **Calorie medie:** 2,500-2,600 kcal/giorno
- **Ciclizzazione:** Surplus nei giorni forza, deficit nei giorni riposo
- **Timing:** Pre e post-workout ottimizzati
- **Supplementi:** Creatina, BCAA, Omega-3, Vitamina D3

## 📈 Monitoraggio

- Test mensili (5km, 10km, 15km, 18km TT)
- Tracking settimanale (km, peso, FC, sonno, energia)
- Misurazioni mensili (peso, circonferenze, foto)
- Settimane scarico ogni 4 settimane

## 🛠️ Attrezzatura Necessaria

- Kettlebell 12 kg
- Manubri regolabili (totale 20 kg)
- Barra trazioni porta (opzionale)
- Elastici resistenza
- Tappetino fitness

**Investimento totale:** €115-175

## 📝 Note

Questo piano è stato creato specificamente per massimizzare la tonificazione muscolare mantenendo ottime performance running. Il volume di corsa è stato ridotto rispetto a piani tradizionali per prevenire il catabolismo muscolare e permettere il recupero adeguato per la crescita muscolare.
